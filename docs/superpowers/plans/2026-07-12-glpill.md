> **Session note:** this plan is executed inline by its author in the same session immediately after writing. Core logic contracts (types, signatures, test cases) are locked here verbatim; SwiftUI view internals are specified by structure + acceptance criteria and verified by build + simulator smoke test.

**Goal:** Ship an App Store-ready SwiftUI iOS app: daily GLP-1 pill tracking with streaks, titration progress, weight trend, side-effect log, doctor report, hard StoreKit 2 paywall.

**Architecture:** SwiftUI + SwiftData (iOS 17+), XcodeGen project, no third-party deps. MVVM-lite: `@Query`-driven views, small `@Observable` stores, pure value-type logic services under `Core/Logic` (fully unit-tested). StoreKit 2 behind `EntitlementProviding` protocol so gating logic is testable.

**Tech Stack:** Swift (language mode 5, Xcode 26.6), SwiftUI, SwiftData, StoreKit 2, Swift Charts, UserNotifications, XCTest, XcodeGen.

### Task 3: Core logic — StreakCalculator, TitrationProgress, WeightStats, UnitFormat (TDD)

**Files:**
- Create: `App/Sources/Core/Logic/StreakCalculator.swift`, `TitrationProgress.swift`, `WeightStats.swift`, `UnitFormat.swift`

Contracts + required cases:
```swift
struct StreakCalculator {
  // dates are dose-log days; today param for determinism
  static func currentStreak(doseDays: [Date], today: Date, calendar: Calendar) -> Int
  // cases: empty->0; today only->1; today+yesterday->2; gap breaks; logged-yesterday-not-today still returns streak (grace: streak alive until day ends) -> yesterday-chain count; duplicate same-day entries count once; longestStreak(...)
  static func longestStreak(doseDays: [Date], calendar: Calendar) -> Int
  static func adherencePercent(doseDays: [Date], from: Date, to: Date, calendar: Calendar) -> Int // 0-100, days with dose / days in window
}
struct TitrationPosition: Equatable { let stepIndex: Int; let dayWithinStep: Int; let nextStepDate: Date? }
struct TitrationProgress {
  // steps sorted by order; each step runs durationWeeks*7 days from plan start (steps chain)
  static func position(steps: [(doseMg: Double, durationWeeks: Int)], planStart: Date, today: Date, calendar: Calendar) -> TitrationPosition?
  // cases: nil for empty; day 0 -> step 0/day 0; boundary day (start+7w) -> step 1/day 0; beyond last step -> last step, nextStepDate nil
}
struct WeightStats {
  static func totalChange(entries: [(date: Date, kg: Double)]) -> Double? // latest - earliest; nil if <2
  static func toGoal(current: Double, goal: Double) -> Double
  static func milestonesReached(startKg: Double, currentKg: Double, stepKg: Double) -> Int // floor(loss/step), 0 if gained
}
enum UnitFormat {
  static func weightString(kilograms: Double, metric: Bool) -> String // "72.5 kg" / "159.8 lb" (1 decimal)
  static func kilograms(fromDisplay value: Double, metric: Bool) -> Double // lb->kg when !metric
  static let kgPerLb = 0.45359237
  static func isValidWeight(kilograms: Double) -> Bool // 25...500
}
```
