# GLPill UX/Product Audit — 2026-07-21

Audit by a subagent wearing the lens of a veteran user of A-list health/medical apps (MacroFactor, MySugr, Zoe, Cal AI, Levels, Oura, Flo, Shotsy, MeAgain) who is also a GLP-1 patient. Grounded in the 15 real rendered screens (`docs/qa/`) + source. Tags: **[new-work]** = touched in the pill-native pass; **[pre-existing]** = older tabs.

## Top findings (highest leverage)

1. **[Critical, pre-existing] Mixed-unit weigh-in silently corrupts the record.** `WeightEntrySheet.swift` — valid ranges 25–500 kg and 55–1100 lb overlap; a kg user typing "180" (meaning lb) is stored as 180 kg. Poisons the trend chart and doctor report. Fix: outlier soft-confirm on save (>~25% deviation from last entry → "big jump — did you mean lb?"), MacroFactor-style. (Pairs with the requested kg/lb toggle.)
2. **[High, new-work] "Not sure" on dose fabricates a dose.** `DoseLadderStep.swift` sets dose to the lowest real dose and shows a confident "3 mg — step 1 of 1" + a med-level curve + a value in the report. Violates the app's honesty positioning. Fix: a true unknown-dose state — hide mg ("dose not set — add in Settings"), honest med-level empty state, omit from report until set.
3. **[High, new-work] Med-level graph's 1–2 dose state looks broken.** `MedicationLevelView.swift` — one dose renders a flat edge-to-edge fill; reads as a bug. Fix: until enough points, show a labeled explainer ("builds over ~7 days — keep logging") with a dashed *projected* curve (Levels/Zoe style). Add a faint baseline to the preview sparkline so "no peak-and-crash" is legible.
4. **[High, new-work] Paywall lists FREE features as premium.** `PaywallView.swift` feature list leads with one-tap logging/streaks/reminders/sync — all free-forever per spec. Fix: mirror the hero's five premium items (PDF report, share cards, advanced widgets, weight projection, export). NOTE: the trial was removed this pass, so ignore the "surface the trial" sub-note. Keep the calm tone + privacy reassurance rows.
5. **[High, pre-existing] Missed doses/gaps are invisible.** `HistoryView.swift` + `ReportScreen.swift` — a missed day looks like a blank day; report shows "86% adherence" with no denominator or longest-gap. Fix: hollow/outlined ring for expected-but-missed days; adherence subtitle with raw counts ("24/28 days") + a "longest gap" line. Strengthens the doctor-report wedge.
6. **[High, both] Accessibility gaps that hit this older/multi-med cohort harder.** Color-only encoding in History (add a glyph/shape); charts have no VoiceOver `AXChartDescriptor`/text fallback (Progress weight chart, MedicationLevelView); sub-44pt tap targets (Progress trash glyph ~20pt, History cells); share/recap cards read as fragmented VoiceOver (combine + composed label).
7. **[High delight, new-work] The wrapped/milestone moment is emotionally flat.** Whole app fires one haptic. Crossing 100/365 days = one spring scale-in, same 🏆 for every tier, no confetti/haptic. Fix (cheap): count-up streak (`.contentTransition(.numericText())`), stagger-fade stat pills, `.success` haptic on reveal, confetti scaled by tier, tiered trophy (🌱→🔥→🏆→👑). Keep the exported card static.
8. **[High, pre-existing] Custom medication name is unbounded.** `MedicationEditor.swift` / onboarding — `customName` stored raw (no trim/cap/empty check); origin of the long-name overflow risk across RitualCard/report/share card. Fix: trim, cap ~40 chars, disable Continue/Save while empty.

## Also worth fixing

**Onboarding**
- [High, new-work] **No Back button** on any onboarding step (`OnboardingFlow`); a mis-tap on medication (step 2, drives the whole branch) is unrecoverable. Add a back affordance.
- [Medium, new-work] Foundayo's truncated flow gives a thin 2-line reveal; add a Foundayo-specific reassurance ("No timing rules — just take it daily").
- [Low, new-work] Plan reveal names only `morningMeds.first`; say "your morning meds + breakfast" when >1.
- [Medium, doc] Spec step 11 "Connect Apple Health" isn't in the built flow. DECISION: Apple Health was intentionally deferred — update the spec to match (not a bug).

**Daily loop**
- [Medium, new-work] FAB quick-add (Water 237 ml / Protein 25 g) has no undo/confirmation. Add an "Added 8 oz — Undo" snackbar.
- [Medium, pre-existing] No retroactive dose logging — History lets you delete a past dose but not add ("I took it, forgot to tap"). Add "Mark as taken" for past days.
- [Low, new-work] FAB overlaps the Protein & Water card; add bottom scroll inset.
- [Low, new-work] The two "Undo" affordances are tiny grey `.caption` text; make the post-log undo more visible.

**Trust / medical**
- [Medium, pre-existing] Silently-broken reminders: if notification auth was previously denied, nothing schedules but the user thinks it did. Detect denied → "Notifications are off — enable in Settings" deep link.
- [Medium, pre-existing] No in-app "delete all my data"; Settings tells users to delete the app manually. Add an in-app reset (also strengthens "Data Not Collected").
- [Medium, pre-existing] Titration editor shows no computed date windows ("3 mg = Aug 12–Sep 8"); add them so users can verify against their prescription.
- [Low, pre-existing] `addStep` defaults to 0.8 mg — contradicts "never suggests doses"; default to empty.

**Consistency / edge cases**
- [Medium, pre-existing] History hardcodes "S M T W T F S" (Sunday-first) while day math uses `firstWeekday`; Monday-first locales shift every dot. Use `calendar.veryShortWeekdaySymbols` + `firstWeekday`.
- [Medium, pre-existing] Duplicate-date weigh-ins allowed → chart double-points, report double-counts. Dedupe.
- [Medium, pre-existing] Report weight-change shows "—" when the only baseline is older than the window (doctor reads as "no data"). Fall back to the last known baseline.
- [Medium, pre-existing] `MorningMedsEditor` keys rows by array index → TextField state can bind to the wrong row on delete. Use `{id, name}` value objects.

## What's already great — don't regress
- Day-3 adherence clamp (avoids "4% of 28 days") — honest, clinician-friendly.
- The `isGain` share card drops celebratory treatment on a gain week — empathetic; extend this care to the Progress "+1.3 kg" badge.
- `RitualState` honesty (`clear(hadWindow:false)` copy) + FDA-sourced, no-advice wait-window explainer — the trust wedge working.
- The morning-sequence card — the actual differentiator; protect it.
- No fake loaders; the plan reveal is a real render.
- Calm palette, generous whitespace, "Free to use. No card needed."

## User-requested changes (this pass)
- Protein & Water → simple `− [editable value] +` steppers (protein ±5 g, water ±50 ml / ±2 oz), tap number to type exact.
- Water → MeAgain-style filling-glass hero (fills per cup, wave + haptic); protein stays a clean bar.
- Weigh-in sheet → inline kg/lb segmented toggle that also heals the app-wide units default.
